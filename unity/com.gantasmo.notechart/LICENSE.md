## Third-party assets

This package ships no font binary. The notation glyphs are rendered from
Bravura, which is licensed under the SIL Open Font License 1.1 and is vendored
in the theDAW repository at
`frontend/node_modules/@coderline/alphatab/dist/font/Bravura.otf`, with the
license text alongside it at `Bravura-OFL.txt`. A project that generates a TMP
font asset from Bravura (see README, "Building the Bravura TMP font asset")
must ship that OFL text with the resulting asset.
