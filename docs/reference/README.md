# theDAW Reference

The complete, code-grounded reference for theDAW: what every feature does, which
models and libraries it uses, and the full HTTP API. Every claim on these pages
cites the source it came from as `path:line`.

## It runs on your machine

theDAW runs on your machine. Once the Stable Audio 3 weights are on disk,
generation, stem separation, analysis, mixing, DJing, notation, and live visuals
all execute locally: the DiT and its SAME autoencoder resolve local-first (local
folder, then the Hugging Face cache, then an optional download that a default-on
`SA3_LOCAL_ONLY` switch can block entirely), gated Stability repos fall back to an
ungated public mirror, and every heavy dependency lives in an isolated sidecar
venv so nothing has to phone home to work. The few network touchpoints are opt-in
and clearly scoped: the Suno song proxy, the multi-provider LLM assistant and its
Gemini/vision helpers, YouTube/URL import, and the TOUR map/route providers.
Server-side keys never reach the browser.

The instrument is built for every kind of player: human performers driving it
through MIDI controllers, the two-deck DJ console, the Perform clip grid, Sway
gestures, and a Quest headset, alongside AI performers generating and transforming
audio through Stable Audio 3, Magenta RT2, and the LoRA models you train yourself
in UNDERFIT. Real or AI-driven, the musicians are yours, and so is the machine
they play on.

See [Offline and performance](../OFFLINE-AND-PERFORMANCE.md) for how a system this
large stays runnable on modest hardware, and exactly which parts are optional cloud.

## How these pages are maintained

These pages were generated by reading the code and citing it. When a feature
changes, update its page in the same change, and keep it registered in the RAG
index (`backend/rag.py`, `DOC_PATHS`) so the in-app assistant answers from the
current text. See also the per-feature walkthroughs in [`docs/guides/`](../guides/)
and the task-oriented [USER_GUIDE](../USER_GUIDE.md), which these pages complement
rather than replace.
